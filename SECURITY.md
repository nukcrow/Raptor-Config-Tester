# Security Policy

## Supported Versions

The following version of Raptor Config Tester is currently supported with security updates.

| Version | Supported |
|---------|-----------|
| 1.0.0   | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Raptor Config Tester, please report it responsibly.

Please do not publish security vulnerabilities in public issues.

When reporting a vulnerability, include:

- A clear description of the issue.
- Steps to reproduce the problem.
- The potential impact.
- Screenshots or logs, if available.

## Security Considerations

Raptor Config Tester may process configuration files and connect to external servers.

For your safety:

- Only use configuration files from sources you trust.
- Do not import files from unknown or suspicious sources.
- Review configurations before testing or using them.
- Do not share private configuration links, credentials, or sensitive logs.
- Download the software only from the official GitHub repository and its Releases page.

## Scope

Security reports should relate to vulnerabilities in Raptor Config Tester itself, including its code, file handling, configuration processing, and bundled components.

Thank you for helping keep Raptor Config Tester secure.
